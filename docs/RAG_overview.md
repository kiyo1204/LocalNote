# RAG（Retrieval-Augmented Generation）とは

**RAG** は「検索拡張生成」と呼ばれる技術で、LocalNoteの核となる仕組みです。

## 仕組み

1. **検索**: ユーザーの質問に関連する情報をベクトルデータベースから検索
2. **拡張**: 検索結果をLLMへのプロンプトに追加（コンテキストとして挿入）
3. **生成**: LLMが参考情報を踏まえて回答を生成

## メリット

- ✅ **最新情報に対応**: モデルの学習データにない情報も扱える
- ✅ **根拠のある回答**: 出典付きで回答できる
- ✅ **コスト効率**: 全データを再学習する必要がない
- ✅ **ドメイン特化**: 専門資料を読み込ませて専門家のように振る舞わせられる

## LocalNoteでの流れ

```
ユーザーの質問
    ↓
質問を履歴を踏まえて再構築（Contextualize）
    ↓
ChromaDBから関連チャンクを検索（MMR + Fair Search）
    ↓
Rerankingで精度向上（オプション）
    ↓
参考情報 + 質問をLLM（Ollama）に送信
    ↓
回答を生成して表示（出典付き）
```

LocalNoteでは、検索 → 再ランク付け → 生成の3段階で高品質な回答を実現しています。
