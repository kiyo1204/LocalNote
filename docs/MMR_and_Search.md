# 検索戦略 — MMR・Fair Search

LocalNoteには3つの検索戦略と、ファイル間の公平検索機能があります。

## 3つの検索戦略

### similarity（類似度検索）
- **最も標準的な検索方法**
- 質問に最も近いチャンクを上位から順に取得
- シンプルで高速だが、似た内容のチャンクが偏りやすい

### MMR検索（Maximum Marginal Relevance）
- **多様性と関連性を両立**
- 高い関連性を持つチャンクを選びつつ、既に選んだチャンクと**似すぎていない**ものを優先
- 異なる角度からの情報を取得できる

**MMR λ（ラムダ）パラメータ**:
| λの値 | 挙動 |
|--------|------|
| 0.0 | 多様性を最大化（いろいろな話題をカバー） |
| 0.5 | バランス型（デフォルト） |
| 1.0 | 関連性のみ（通常の類似度検索と同じ） |

### hybrid（ハイブリッド検索）
- **類似度 + キーワードの複合検索**
- ベクトル類似度だけでは拾えないキーワード一致も考慮

## Fair Search（公平検索）

**問題**: ファイル数が不均等な場合、大きいファイルの情報ばかりが検索される

**解決**: 各ソースファイルから均等にチャンクを取得する

**動作**:
- 例えば3つのファイル（A:100チャンク, B:10チャンク, C:5チャンク）でK=6の場合
- 各ファイルから2チャンクずつ取得（6÷3=2）
- ラウンドロビンでインターリーブ（A1→B1→C1→A2→B2→C2）

Fair Searchを有効にすると、どのファイルも均等に考慮されるため、
**小規模な資料の内容も見落とされにくくなります**。
