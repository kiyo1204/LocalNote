# ChromaDB — ベクトルデータベース

**ChromaDB** はオープンソースのベクトルデータベースです。
文章を「埋め込みベクトル」（数値の配列）に変換して保存・検索します。

## なぜベクトルDBが必要か？

LLMは大量のテキストを一度に処理できません。
そこで、資料を小さな**チャンク**に分割し、それぞれをベクトル化してChromaDBに保存します。
質問が来たら、質問のベクトルと近いチャンクを高速に検索します。

## LocalNoteでの使い方

### 保存の流れ
```
PDF/Markdown/Officeファイル
    ↓ チャンク分割（数百〜数千文字単位）
複数のチャンク
    ↓ 埋め込みベクトル化（E5モデル）
ベクトル + テキスト + メタデータ（出典等）
    ↓ ChromaDBに保存
chroma.sqlite3
```

### 検索の流れ
```
ユーザーの質問
    ↓ 同じモデルでベクトル化
質問ベクトル
    ↓ 類似度検索（コサイン類似度）
関連チャンクを取得（K件）
```

### 保存場所
- `./db/チャット名/` ディレクトリ内に `chroma.sqlite3` として保存
- チャットごとに独立したデータベースを持つ

### 主な機能
- **フィルター検索**: 特定のファイルからのみ検索
- **MMR検索**: 多様性を考慮した検索
- **メタデータ保存**: 出典ファイル名・ページ番号・座標情報などを保持
