# 座標ベースチャンキング — PDFの高度な解析

通常のテキスト分割（文字数ベース）では、PDFの**レイアウト情報**が失われてしまいます。
LocalNoteの座標ベースチャンキングは、PDF内の文字の**位置情報**を活用して、
より意味のある単位でチャンク分割を行います。

## 従来の方式の問題点

```
従来方式:
「こんにちは。 今日はいい天気ですね。」 ← レイアウト無視
        ↓ 単純な文字数分割
「こんにちは。 今日は」 / 「いい天気ですね。」 ← 文が途中で切れる
```

## 座標ベースチャンキングの仕組み

```
PDFの各文字に座標（x, y）を付与
    ↓
同じ行・同じ段落の文字をグループ化
    ↓
縦書き・横書きを自動判別
    ↓
意味のあるブロックに分割
```

## 対応するレイアウト

- **横書きテキスト**: 一般的な文章（英語・横書き日本語）
- **縦書きテキスト**: 日本語の縦書き文書
- **2段組み**: 学術論文などの2カラムレイアウト
- **混在**: 縦書きと横書きが混ざった文書も自動判別

## パラメータ

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| eps | 15.0 | 文字同士を同じグループと判定する距離 |
| min_chars | 3 | 最小チャンク文字数 |
| direction_threshold | 0.7 | 縦/横判定の感度 |

## メリット

- ✅ 文の途中で切れないチャンク分割
- ✅ 表や図のキャプションを適切に保持
- ✅ 段組の文書でも正しい読順を維持
- ✅ 出典座標をメタデータとして保持（元のPDF位置が特定可能）
